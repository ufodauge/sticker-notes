# 瓶の物理エンジン比較(rapier3d → Jolt)

2026-11-25。3D の瓶の物理を rapier3d-compat 0.21 から Jolt Physics(`jolt-physics` 1.1.2、公式 WASM、MIT)へ載せ替え、同じ条件で測った。ブランチの既定は Jolt。

## 実寸と定数(`src/core/jar3d.ts` の `PHYSICS3D`、両エンジン共通)

- 1 単位 = 3.3 cm。瓶 5.2 単位 = 17 cm、ブロック 1.25 × 0.36 単位 = 4.1 × 1.2 cm。
- 重力 9.81 m/s² = 297 単位/s²(旧 20)。密度はアクリル 1180、ガラス 2500 kg/m³ を単位³ に換算(ブロック約 14 g)。
- 摩擦: アクリル 0.5、ガラス 0.32、机 0.5(Jolt は積の平方根、rapier は平均で、アクリル同士 0.5・対ガラス約 0.4・対木 0.5)。反発 0.1。
- 減衰: ブロックは線 0、角 0.05。瓶だけは「手で持っている」減衰(旧値 × √(重力比))。
- 速度・ドラッグ・振る強さ・瓶の引きなどの旧定数は √(重力比) ≈ 3.86 倍(加速度は 14.9 倍)して体感の速さをそろえた。速度上限 42 単位/s(1.3 m/s)は両方に残した。
- 計測ビルド(`VITE_JAR_PROBE`)は品質段階に関係なく 1/60 s 固定の刻み(遅いソフトウェア描画で 30 Hz に落ちて条件が変わらないように)。

## 計測(`e2e/jar-physics.perf.spec.ts`、`JAR_PHYSICS=1`、Chromium のソフトウェア WebGL、40 枚)

落ち着くまでの刻み数(上限 150 s)、20 s 時点の「震え」(角速度 > 1 rad/s かつ速度 < 0.3)、10 回振った 8 s 後の瓶外の枚数、物理の 1 刻み(=60 Hz の 1 フレーム)あたりの時間。全員出し終わるのは両方とも約 690 刻み目(出し方が 1 フレームに 1 枚のため)。

| | rapier(実寸) | Jolt |
| --- | --- | --- |
| 落ち着くまでの刻み(中央値、範囲) | 4080(1280〜5536)、n=10 | 1184(1168〜1264)、n=7 |
| 出し終わってから落ち着くまで | 約 3400 刻み(57 s) | 約 500 刻み(8 s) |
| 落ち着かなかった | 0/10 | 0/7 |
| 山の強制スリープなしで落ち着くまで | 6608、12288、落ち着かず(n=3) | 1184 ×3 |
| 20 s 時点で起きている / 震え | 7/10 回で 40 枚とも起きている、震え 0〜2 枚 | 全回 20 s 前に静止(0 / 0) |
| 振った後に瓶の外 | 計 6 枚(10 回中 4 回で 1〜2 枚) | 計 1 枚(10 回中 1 回) |
| 振って 8 s 後もまだ動いている | 10 回中 4 回 | 10 回中 0 回 |
| ガラスにめり込んだまま(重心が壁の中) | 0 | 0 |
| 物理 ms / 刻み(中央値) | 3.9(2.1〜4.6) | 0.61(0.53〜0.84) |
| 瓶のチャンク | Jar.js 5.05 MB(gzip 1.84 / br 1.35 MB、WASM を base64 で内包) | Jar.js 1.66 MB + jolt .wasm 2.03 MB(gzip 0.33+0.75 / br 0.25+0.51 MB) |

いずれも three.js を含む。Jolt の WASM は瓶を開いたときだけ取得し、Service Worker の `jar-chunk` キャッシュに入る。止まっている瓶を Jolt で凸の部品(141 個)にしても結果は同じ(2 回: 1168 刻み、漏れ 0、0.57 ms)。滑らかなメッシュを既定にした。

## 見たこと

- rapier は実寸の重力で山が長く動き続ける。強制スリープ(45 刻みでほぼ動かなければ眠らせる)を外すと 3 回中 1 回は 150 s で止まらない。Jolt は強制スリープの有無で結果が変わらず、自前のスリープだけで出し終わりから 8 s で止まる。
- 画像では両方とも山は自然で、ガラスへのめり込みや浮きは見えない(重心がガラスの中にある枚数も両方 0)。
- Jolt で 1 枚漏れた回は、振った後に瓶の手前の机に 1 枚落ちていた。縁を越えたか壁を抜けたかは未確定。
- Jolt の衝突音は接触の法線方向の相対速度で出している(以前は物体の速さ)。音の大きさは未調整。

## 判断

**Go。** 落ち着く速さ(約 7 倍)、物理の重さ(約 1/6)、配る大きさ(gzip で約 6 割)、漏れのどれも Jolt が上回り、実寸の重力でも安定している。

## 残り

- 実機(スマホで 40〜120 枚)のフレーム時間と WASM の読み込み時間。ここの数字はデスクトップのソフトウェア描画の上。
- 瓶を掴んで傾ける・倒す、傾きセンサーの重力、音量の聞き比べは手で未確認(E2E は振るとリセットまで)。
- 強制スリープ(`sleepPileWhenCalm`)と速度上限は Jolt では外せる見込み。外して漏れが増えないかを回数を増やして確かめる。
- 縁越えか壁抜けかを区別する計測(振った瞬間の高さを記録)。
- `?pieces=1` / `?pilesleep=0` / `?hull=1` は計測用のクエリ。残すか決める。
