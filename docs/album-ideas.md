# シール帳を遊び場にする

瓶はおもちゃとして触りたくなるが、シール帳は「持っているものを確かめる場所」に寄っていた。貼る前(手に入れる瞬間)と貼った後(眺める・見せる)に楽しさを足す。

ガチャ的なレア度や発行枚数の限定はやらない(交換の温かさと合わない)。

## 1. シールポケット(手に入れる儀式)

- 受け取ったシールも、自分で作ったシールも、まずシール帳の端の透明なポケットに雑に突っ込まれる(ページには貼られない)。数のバッジが付く
- ポケットを開くと、裏紙の付いたシールが重なって入っている。1 枚選ぶと裏紙ごと手元に出てくる
- 裏紙には「from 〇〇・日付」(自分のものは「作った日」)
- 角をめくるようにドラッグすると裏紙がはがれ、そのまま指に付いてくる。ページの上で離すとそこに置かれる
- 置いた直後は少し浮いている(影が大きい)。押さえると、ぺたっと貼り付く
- キーボードや支援技術では「はがしてページに貼る」ボタンで、いま開いているページの空いた所に置く

データ: ポケットは「置き場所(placement)のないシール」。新しい保存領域は作らない。バックアップの読み込みで置き場所のないシールもポケットに入る。

## 2. シールの裏と、くれた人

- シールを選んで「裏を見る」と、ひっくり返って裏が見える: くれた人(SNS)、日付、素材
- QR を出せるのは自分のシールだけなので、受け取ったシールの SNS は、くれた人と同じ
- 「もらった人」: 人ごとに枚数と最初にもらった日、その人のシール

## 3. 素材(作った人が決め、シールと一緒に渡る)

| 素材 | 見え方 |
| --- | --- |
| ふつう | 今のまま |
| キラ | 傾ける(パソコンではポインタを動かす)と虹色が流れる |
| ぷっくり | つやのある盛り上がり。ハイライトが傾きで動く |
| ラメ | 細かい粒がまたたく |
| 箔 | パレットの 1 色が金属になる |
| 蓄光 | 暗い瓶の中で淡く光る |
| クリア | 下地の白がなく、台紙がうっすら透ける |

payload: 本体の末尾に 1 バイト足す(上位 4 ビットが素材、下位 4 ビットが箔の色番号)。「ふつう」は 1 バイトを足さないので、今までのシールと ID・リンク・`test/vectors/payload-v1.json` はそのまま。

後回し: 見る角度で 2 枚の絵が切り替わる(レンチキュラー)。絵が 2 枚要り、payload が倍になる。

### 素材は交換で増える

- 最初に使えるのは「ふつう」と数種類だけ。交換した相手(受け取ったシールの SNS の数)が増えるごとに、作るときに選べる素材が増える
- 数えるのは「人」: 同じ人から何枚もらっても 1。交換を促すためで、競わせるためではない(ランキングや数の表示を前に出さない)
- 次の素材が何人目で使えるかは、作る画面の素材の欄に鍵で見せる
- 端末の中だけで数える。ID を増やせばごまかせるが、遊びなので構わない

## 4. 明かりを消す(蓄光と合わせて)

- シール帳に電気のスイッチ。消すと台紙まわりが暗くなり、蓄光のシールだけが淡く光る。指(パソコンではポインタ)の所だけ懐中電灯で照らされる
- 周りの明るさとの連動: ブラウザの照度センサー(`AmbientLightSensor`)は Chrome でもフラグの奥で、iOS にはない。カメラで明るさを測る手はあるが、カメラの許可を求めるほどの機能ではない。まずはスイッチだけにし、センサーが使える環境でだけ「暗くなったら自動で消灯」を足す

## 5. めくる

- シール帳は見開きのノート。1 枚の紙(リーフ)の表と裏が 1 ページずつで、めくった紙は左に重なる
- 広い画面は見開き全体、狭い画面は片側だけを見せ、もう片側を端に少しのぞかせる。左右の移動は横に滑らせる
- 紙の空いた所を横にドラッグすると、紙が指についてくる。速く動かすほど自由な端が遅れてしなる(skew)。離すと、3 分の 1 を超えたか、はじいたらめくれる
- ホイール、ページの目盛り、シールを持ったまま画面の端で止める、でもめくれる
- 3D の紙が重なると、ブラウザの当たり判定が z-index どおりにならない。止まっているときは開いている 2 ページだけを残し、ほかは隠す

## 6. シールをはがして動かす

- 触れるのはシールの形の中だけ(輪郭から作った clip-path)
- 引っぱると、指の側がめくれ上がり、反対の端を支点に折れていく。シールの大きさの 6 割ほど引くとはがれて、指について浮く(グラブした位置のまま)
- ページの上で離すとそこに貼り付く。紙の外なら元の場所に戻る。ポケットの上ならポケットに戻る
- 2 本指はその場で回転と拡大縮小(今までどおり)
