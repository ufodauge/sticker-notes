# 3D の机(2026-11-28 に採用)

斜め上から見下ろす 3D の机を、これからのシール帳の場面にする(オーナーのスケッチと試作 `?room` で確かめた)。アセットとエフェクトの作り込みは別に詰める。

## 構図(試作で決めたもの)

- 部屋の壁に、奥に行くほど狭まる凹み(ウィンドウシート)。座面は机とほぼ同じ高さ、奥に大きな窓。座面には観葉植物だけ
- 机はウィンドウシートの前にくっつけて置く。机の上: 左奥にブックスタンド(帳面を立てる)、右奥にノート PC とランプ、手前に開いた帳面。机の前面に引き出し
- 見下ろす角度は固定(回転なし)。ピンチ・ホイールで寄る、ドラッグで動く(机の外へは出ない)
- 光: 時刻と季節で太陽の高さと向き、窓枠の影が座面と机に落ちる。夜はランプ。天気(晴れ・くもり・雨・雪)
- 弱い端末には警告し、軽く描く(影なし、低解像度)

## これからすること(順に)

1. 今のシール帳の機能を 3D の机に載せる
   - 帳面: 机の上の帳面に本物のページ(貼ったシール)を描く。帳面を押すと寄って、貼る・剥がすは今の 2D の帳面をその位置に重ねて行う(寄った絵と 2D の帳面がつながって見えるように)
   - 引き出し: 机の前面の引き出しが開き、捨てたシールが中に見える。押すと今の引き出しの画面
   - ポケット: 机の上の物の一つとして置く(位置は並べかえで変えられる)
   - ブックスタンド: 帳面を何冊も持てるようにする(データに「帳面」を足す)
2. デザイナーが参加しやすいよう、モデルとテクスチャをファイルから読み込む(glTF と画像)。コードで描いている今の形は、ファイルがないときの代わりとして残す
   - できた: `src/ui/room/room-assets.ts` の表(机、ノート PC、観葉植物、ランプ、ブックスタンド、窓枠、机・床・壁のテクスチャ)、`public/room/manifest.json`、決まりごと `docs/room-assets.md`。見本に観葉植物 `public/room/plant.glb`(コードから書き出し)
   - のこり: 帳面の表紙と紙(1 の帳面の作業のあと)、引き出しの前板、ランプのシェードの光り方をファイル側で決める、KTX2 などの圧縮テクスチャ
3. アセットとエフェクトの作り込み

## 1 の進み具合(試作 `?room` の中で。本番の画面はまだ 2D のまま)

できたこと:

- 帳面: 机の上の帳面のページに、開いている見開きを本物のシールで描く(2D の帳面と同じ描き方 `page-paint.ts`)。ストアが変わるたび、めくるたびに描き直す。帳面を押すとカメラが真上へ降りて、見開きが 2D の帳面と同じ大きさ・位置に来る。着いたら 2D の帳面(`Album.tsx`)が上にふわっと出て、剥がす・貼る・めくる・選んで捨てる(引き出しへ)・QR・裏がそのまま使える。帳面の横を押す(またはホイールを戻す、2 本指を寄せる)と 2D が消えてカメラが元の位置へ戻る。狭い画面で 2D の帳面が左右に滑ると、カメラも追う
- 引き出し: 机の前面の板を押すと引き出しが滑り出て、捨てたシールが底に小さく散らばって見える。開いた中を押すと今の引き出しの画面(`DrawerDialog`)。前板をもう一度押すと閉まる
- ポケット: 透明なポケットを机の上の物の一つとして置く(並べかえで動かせる)。もらったシールが数枚、口からのぞく。押すと今のポケットの画面(`PocketDialog`)
- 時刻・天気・並べかえの操作は畳んだ紙の札にした(小さな画面で机の前面が隠れないように)
- e2e: `e2e/room.spec.ts`(3D の物は、場面が教える画面上の位置 `window.__room.where(...)` を押す)

残っていること:

- 本物の帳面は 1 冊だけ(データに帳面が 1 つしかない)。スタンドの最初の 1 冊(左端)が本物で、ほかは飾り。飾りの帳面は押すとスタンドに戻り、本物は押すと寄る。本物をしまうのは並べかえ中に押したとき(背表紙を押すとまた出る)。帳面を何冊も持つにはデータに「帳面」を足す
- 本番の画面(`App.tsx` の `DeskView`)はまだ 2D。3D に置き換えるときに、作る・印刷・メニュー・チュートリアル・トースト・交換の流れを 3D の画面に載せる(試作は帳面・引き出し・ポケットと、選んだシールの操作だけ)
- 寄っているあいだ、3D の帳面は 2D の帳面の下に隠れている。2D の帳面が滑ったあと、カメラが追いつくまで少し遅れる
- 机の上に貼ったシール(`DeskTop.tsx`)は 3D の机にまだない
