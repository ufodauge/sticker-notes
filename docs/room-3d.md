# 3D の机(2026-11-28 に採用)

斜め上から見下ろす 3D の机を、これからのシール帳の場面にする(オーナーのスケッチと試作 `?room` で確かめた)。アセットとエフェクトの作り込みは別に詰める。

## 構図(試作で決めたもの)

- 部屋の壁に、奥に行くほど狭まる凹み(ウィンドウシート)。座面は机とほぼ同じ高さ、奥に大きな窓。座面には観葉植物だけ
- 机はウィンドウシートの前にくっつけて置く。机の上: 左奥にブックスタンド(帳面を立てる)、右奥にノート PC とランプ、手前に開いた帳面。机の前面に引き出し
- 見下ろす角度は固定(回転なし)。ピンチ・ホイールで寄る、ドラッグで動く(机の外へは出ない)
- 光: 時刻と季節で太陽の高さと向き、窓枠の影が座面と机に落ちる。夜はランプ。天気(晴れ・くもり・雨・雪)
- 弱い端末には警告し、軽く描く(影なし、低解像度)

## これからすること(順に)

1. 今のシール帳の機能を 3D の机に載せる
   - 帳面: 机の上の帳面に本物のページ(貼ったシール)を描く。帳面を押すと寄って、貼る・剥がすは今の 2D の帳面をその位置に重ねて行う(寄った絵と 2D の帳面がつながって見えるように)
   - 引き出し: 机の前面の引き出しが開き、捨てたシールが中に見える。押すと今の引き出しの画面
   - ポケット: 机の上の物の一つとして置く(位置は並べかえで変えられる)
   - ブックスタンド: 帳面を何冊も持てるようにする(データに「帳面」を足す)
2. デザイナーが参加しやすいよう、モデルとテクスチャをファイルから読み込む(glTF と画像)。コードで描いている今の形は、ファイルがないときの代わりとして残す
   - できた: `src/ui/room/room-assets.ts` の表(机、ノート PC、観葉植物、ランプ、ブックスタンド、窓枠、机・床・壁のテクスチャ)、`public/room/manifest.json`、決まりごと `docs/room-assets.md`。見本に観葉植物 `public/room/plant.glb`(コードから書き出し)
   - のこり: 帳面の表紙と紙(1 の帳面の作業のあと)、引き出しの前板、ランプのシェードの光り方をファイル側で決める、KTX2 などの圧縮テクスチャ
3. アセットとエフェクトの作り込み
