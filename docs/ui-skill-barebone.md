# UI 規約

UI を作成・改修するときの規約。利用者が繰り返し指摘した点と、実装で固めた構成をまとめる。

## 前提

以下を参考にする

- https://developer.chrome.com/docs/modern-web-guidance?hl=ja

## 文言のルール（最重要）
- 「。」を書かない。箇条書きを主体に短く書く。
- 情報はアイコンや記号で伝え、詳しい説明はタップで開くダイアログに置く。
- 条件は主語を明示し、読点で区切る。長い一文にせず、改行で分ける。
- 専門用語など、長い情報が必要な場合はツールチップなどを出す。
