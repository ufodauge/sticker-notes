# 机の上のシール帳(場面・机・驚き)の検討

2026-11-26。蓄光と懐中電灯を削除したあとの、次の楽しさの案。「導線ごとの驚き」「ノート PC に貼る」と合わせて考える。

## 決定(2026-11-26)

- 光は**端末の時計だけ**で決まる。切り替えボタンは作らない(制限があるほうが面白い)
- 場面はワイヤーフレーム調から外れてよい。UI(ボタン、ダイアログ)は今のまま
- 光と机(貼れる物)の**両方**を入れる
- 状況: 光は実装済み(`core/daylight.ts`、`ui/scene/`)。昼は何も重ねない(重さのため)。机のマット(4 枚)とノート PC(3 人目で届く、16 枚)は実装済み(`core/surface.ts`、`ui/scene/DeskSurfaces.tsx`)。物は台の部分をつかんで机の上で動かせる(縦長と横長の画面で別々に覚える)。3D はやめ、貼れる物は本・ノート PC など平面のものに絞る(2026-11-26 決定)。ピンチで机全体を見る操作は未着手

## 1. 場面: 時間で変わる机の上

シール帳は部屋の机の上にある。端末の時計で、光が変わる(センサーは要らない)。

| 時間 | 光 | 小物 |
| --- | --- | --- |
| 朝(5〜10 時) | 窓からの白っぽい光。影は短く、片側にやわらかく落ちる | 観葉植物の葉の影がページにかかる |
| 昼 | 明るく均一(今の見た目に近い) | — |
| 夕方(16〜19 時) | 低い橙の光。窓枠の影が入った長い日だまりと、長い影(はじめのブラインドの縞は現実感がなく、窓枠に変えた) | 植物の影が長く伸びる |
| 夜 | 机のライトの丸い光だまり。外側は暗い | ライトの笠、マグカップ |

- 「電気を消す」ボタンは削除した。光は時計だけで決まる(上の決定)
- 光はシール帳とシールの両方にかかる。**素材が光で違って見える**ようにすると、素材を選ぶ理由になる: キラは夕日で虹色が強く出る、箔はライトの方向にきらっと光る、クリアは窓の光を透かす
- 植物の影は、風でゆっくり揺れる(動きを減らす設定では止める)
- 描き方: 背景(机の木目、窓の光)は CSS のグラデーションと SVG 1 枚。影はページの上に重ねる半透明の層。シールの光沢は今の `--x` などの変数を光の向きから決める

UI の規約(ワイヤーフレーム調、色はステッカーだけ)との関係: 場面は「舞台」として規約の外に置き、ツールバーやダイアログは今のまま線と紙だけにする。

## 2. 机にも貼れる(特別な枠)

- シール帳の外、机の天板に**数枚だけ**貼れる場所を作る。お気に入りや、特別な人のシールを置く場所
- ノート PC、スマホケース、水筒など、**貼れる物**が机に増えていく。物ごとに地の色と質感が違い(PC はアルミのつや消し、水筒は曲面)、自由に重ね貼りできる
- 物は交換した人数で机に届く(素材の解放と同じ仕組み)。例: 机 = 最初から、ノート PC = 3 人、スマホケース = 6 人、水筒 = 10 人
- スマホでは、シール帳をピンチで縮めると机全体が見え、物をタップするとそこへ寄る
- データ: 貼る場所は「ページ」と同じ扱いで、`pageId` の代わりに面の ID(`desk`、`laptop` など)を持つ。ペイロードは変わらない。バックアップの形式は変わる(未公開なので移行は不要)

## 3. 導線ごとの驚き

| 場面 | 今 | 案 |
| --- | --- | --- |
| 受け取る | 飛んできてポケットへ | 相手が初めての人なら、机の上に「〇人目」のスタンプが一瞬押される |
| 素材が使えるようになる | 作るボタンに点、選ぶ画面で演出 | その素材の見本シールが 1 枚ポケットに届く(はがして貼れる) |
| 物が届く | — | ノート PC などが机の端から滑り込んでくる。最初の 1 枚を貼る場所が点線で光る |
| ページが埋まる | 次の空の見開きが出る | 最後の 1 枚を貼ると、紙が少し浮いて次のページが顔を出す |
| 1 日の最初に開く | — | その時間の光が、窓からゆっくり差し込んでくる |

## 4. 進め方の案

1. 場面(時計まかせの光と影、植物の影)。削除した蓄光の代わり。実装済み
2. 光で変わる素材の見え方
3. 机に貼れる枠と、届く物(ノート PC から)
4. 導線の驚きを 1 つずつ
