# 瓶と机のモデル(glTF)

3D の瓶モードは、瓶と机の形を `src/ui/jar3d/models/jar.gltf` から読み込む。コードの中で形を作らないので、Blender などで開いて形を直し、書き出せばそのまま反映される(ビルドに取り込まれる。外部から取りに行かない)。

## 単位と向き

- glTF の標準どおり、Y が上、1 単位はシーンの 1 単位。目安はブロック 1 個の幅が 1.25、瓶の高さが 5.2。
- 机の上面が Y = 0。瓶の底は Y = 0 に置く。
- 物理もこの単位で計算する(実際の大きさとの換算は物理の設定側で持つ)。

## ノード名の決まり

| ノード名 | 中身 | 必須 |
| --- | --- | --- |
| `jar` | 瓶の見た目。子のメッシュをすべて描く。マテリアル名が `glass` のメッシュは、アプリのガラスの質感(表と裏の 2 枚描き、縁の光)に置き換わる。それ以外のマテリアルはそのまま使う | 必須 |
| `jar_collision` | 置いてある瓶の当たり判定。子のメッシュの三角形をそのまま使う(滑らかで、山が落ち着きやすい)。なければ `jar` のメッシュを使う | 任意 |
| `jar_pieces` | 掴んで動かしている瓶の当たり判定。子のメッシュ 1 つが凸な部品 1 つ(頂点の凸包として扱う)。動く物体は凸な部品の集まりでしか表せないため | 任意(なければ瓶を掴んでも動かない) |
| `lid` | ふたの見た目(瓶と一緒に動く)。マテリアル名が `lid` のメッシュは金属の質感に置き換わる。ふたのボタンで表示が切り替わる | 任意 |
| `lid_collision` | ふたの当たり判定。子のメッシュ 1 つが凸な部品 1 つ。今は外のキャップと、首に差し込む栓の 2 つ | 任意(なければふたは見た目だけ) |
| `desk` | 机の見た目。マテリアル名が `wood` のメッシュは、木目と周りへのフェードに置き換わる | 任意 |
| `spawn` | ブロックを落とす位置(空のノード。高さだけ使う) | 任意 |

`jar_collision` と `jar_pieces` の下のメッシュは描画しない。見た目と当たり判定がずれると、ブロックが壁の手前で止まったり、壁にめり込んで見えたりするので、形を直したら当たり判定も合わせる。

## 作り直す

今のファイルは、コードの断面(`src/core/jar3d.ts`)から書き出したもの。断面を変えて作り直すときは次を実行する。

```sh
node scripts/export-jar-model.ts
```

Blender で直す場合は、このファイルを読み込み、編集して glTF(`.gltf`、埋め込み)で同じ場所に書き出す。ノード名とマテリアル名は上の表のまま残すこと。
