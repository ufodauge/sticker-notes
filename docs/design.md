# 見た目を触る人のための入口

画面は 2 層。触る場所が違う。

| 層 | 何か | 値の置き場所 |
| --- | --- | --- |
| UI | ツールバー、ダイアログ、トースト、ボタン。机の上の紙(テープで留めたノートの紙、紙の札、付箋)。紙はテーマによらず紙の色、アクセントカラーなし | `src/styles/tokens.css` |
| 場面 | 机、シール帳の表紙と紙、時刻の光、観葉植物の影、シールの素材(キラ・箔など) | `src/styles/scene.css` |

- 色や光の強さは、上の 2 ファイルの値を変えれば画面全体に反映される。各値にコメントで用途を書いてある
- 光が時刻でどう変わるか(朝・昼・夕方・夜の強さの移り変わり)は `src/core/daylight.ts` の `KEYS`。昼は重さのため何も重ねない
- 絵のファイル: 観葉植物の影の形は `src/assets/scene/plant.svg`(形だけが使われる。色・ぼかし・濃さは `scene.css`)。差し替えればそのまま使われる
- アイコンは lucide-react(コードの中で指定)
- 規約(文言、動き、レイアウト)は `.claude/skills/ui-conventions/SKILL.md`

## 確かめ方

- `vp dev` で `?samples` を付けて開くと、見本のページが出る: 朝・昼・夕方・夜の 4 つの光のそれぞれで、6 つの素材を並べたもの。準備なしでデザインレビューに使える。e2e(`e2e/samples.spec.ts`)が同じページを `test-results/samples.png` に撮る
- `vp dev` で開き、`?debug` を付けると右上にデバッグのボタンが出る。デバッグメニューで時刻を選ぶと、その時刻の光で見られる。素材をすべて解放するスイッチ、交換をためすボタンもある
- デバッグメニューは本番のビルドには入らない(`src/ui/debug-build.ts`)

## 画面の組み立て(コードの地図)

- `src/ui/App.tsx`: ツールバー、場面、ダイアログ類を並べるだけ
- 場面: `src/ui/scene/DeskView.tsx`(画面より広い机、木目、机に貼ったシール、真ん中のシール帳)、`Room.tsx`(時刻の光)、`DeskTop.tsx`(机に貼ったシールの扱い)
- シール帳: `src/ui/album/`(ページめくり、剥がす・貼る、ポケット、机の引き出し(捨てたシールが入り、取り出せる。`Drawer.tsx`))
- ツールバーのアイコン: `src/ui/PixelIcon.tsx`(16×16 のドット絵をそのまま書く)
- 3D の机(`?room`、`docs/room-3d.md`): `src/ui/room/Room3D.tsx`(操作の板)、`room-scene.ts`(three.js の場面。物はコードで描く)、`room-assets.ts`(物の名前の表。`public/room/` にファイルがあれば、コードの形と入れ替える)。モデルとテクスチャの決まりは `docs/room-assets.md`

## 出来事と流れ

- アプリで起きたこと(剥がした、貼った、ポケットに戻した、めくった、受け取った、作るを開いた、作った、QR を閉じた)は、起きた場所から `events`(`src/data/events.ts`)に流す。種類は `src/core/events.ts`
- チュートリアルや交換の「流れ」は `src/core/flows.ts` にデータとして書く(状態の並びと、各状態から次へ進む出来事)。テストも見取り図もこの表から作る
- チュートリアルは言葉で説明しない。本物の物が自分で合図する(見本の一枚の端が本物の剥がれと同じ描き方でめくれては戻る、ページの角が折れかける、作るボタンやポケットが脈打つ)。しばらく何もしないときだけ指が手本を見せる。言葉は最後のカード 1 枚だけ(交換のしかたを名詞の題で)。初回の流れは「剥がす → 貼る → めくる(次のページに見本) → 自分のを作る(写真を選ぶだけ。作ったシールはページに貼られる) → 友だちのシールがポケットに届く(札は「友だちから」) → 貼る」で、交換のアプリだということを体験で伝える。途中でやめる手段は置かない(通り抜けて終わる)。ただし作るのは断れる: 何も作らずに作る画面を閉じても、そのまま先へ進む(リンクから来た人は、そこで終わる)。自分で作ったシールは、チュートリアルに限らずいつもページに貼られる(ポケットはもらったものだけ)。チュートリアルで作る一枚は、写真を選ぶだけで出来上がる(選ぶものを出さない)
- 出来事への反応(初めての人のスタンプなど)は `src/ui/reactions.ts`、チュートリアルは `src/ui/tutorial/tutorial-store.ts`
- 確かめ方: デバッグビルドでデバッグメニュー → 「流れを見る」。流れごとの状態の並び、今いる状態、起きた出来事の記録が出る。出来事は手で起こせ、チュートリアルは状態をクリックするとそこへ飛ぶ
